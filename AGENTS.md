# AGENTS

Инструкции для coding-агентов и автоматизированных правок в этом репозитории.

## 1) Цель проекта

Поддерживать ретро-портал SCU на Next.js, сохраняя:

- визуальный стиль old-school терминала
- контентную структуру и тональность
- стабильные переходы/FX

## 2) Что можно менять безопасно

- текст и структуры в `content/*.ts`
- верстку страниц в `app/*/page.tsx`
- UI-компоненты в `components/*`
- стили в `styles/retro.css` и `app/globals.css`
- типы в `types/*`

## 3) Что менять осторожно

- `context/FxContext.tsx` (звук, transition, localStorage)
- `components/RetroLink.tsx` (навигация и блокировки во время перехода)
- `components/RouteFxOverlay.tsx` (boot overlay и timing)

Любые изменения в этих файлах требуют ручной проверки переходов между всеми страницами.

## 4) Жесткие правила

- Не добавлять лишние зависимости без необходимости.
- Не ломать статическую сборку (`next build` должен проходить).
- Не убирать safe mode.
- Не менять ключ хранения `scu-retro-prefs-v1` без миграционного плана.
- Не заменять ретро-стиль на современный UI-лонгрид.

## 5) Добавление нового раздела

1. Создать страницу `app/<route>/page.tsx`.
2. Добавить контентный модуль в `content/` (если нужен отдельный набор данных).
3. Добавить ссылку в `content/nav.ts`.
4. Обновить `types/site.ts` при появлении нового route key.
5. Проверить переходы через `RetroLink`.

## 6) Проверка перед завершением задачи

Обязательно выполнить:

```bash
npm run lint
npm run build
```

Если не запускалось, явно указать это в отчете.

## 7) Формат отчета агентом

Отчет должен включать:

- какие файлы изменены
- что изменено функционально
- результаты `lint/build`
- оставшиеся риски или ограничения

## 8) Неочевидные детали проекта

- Тексты могут содержать редактированные/засекреченные фрагменты (`[ДАННЫЕ УДАЛЕНЫ]`, `███`) и это часть дизайна.
- `Redacted` используется как визуальный паттерн, не удалять без замены на эквивалентный механизм.
- Значимая часть UX построена на анимациях CRT/overlay; оптимизировать их можно только без потери общей эстетики.
