# Базовый дизайн (source of truth)

Этот документ фиксирует базовый внешний стиль проекта, который считается эталонным.

## 1) Что считается базовым дизайном

- Классический retro SCU-вид:
  - синий служебный header,
  - серо-металлический фон/панель,
  - стандартные старые рамки/табличные блоки,
  - типографика в стиле системного UI.

## 2) Где лежит базовый дизайн

- `app/globals.css` — базовые глобальные стили страницы (`body`, reset, базовый шрифт).
- `styles/retro.css` — основной визуальный слой интерфейса (layout, карточки, таблицы, ретро-тема).

Эти два файла являются источником истины для внешнего вида.

## 3) Важно по FX-кнопке

- В конце `styles/retro.css` допускается блок `.fx-off ...`, связанный с кнопкой `FX ON/OFF`.
- Этот блок относится к управлению отображением FX, но не заменяет базовую тему и должен сохраняться.

## 4) Правило для будущих правок

Если задача не просит полный редизайн, ориентироваться на текущий baseline из:

- `app/globals.css`
- `styles/retro.css`

и не вводить альтернативные theme-override блоки поверх базовой темы без явного запроса.
